EShoppingZone - Low Level Design (LLD)
1. System Overview
EShoppingZone is an e-commerce platform where:
* Users browse products
* Add/remove items from cart
* Place orders
* Pay using wallet or Cash on Delivery
* View previous orders
* Update profile
Two major actors:
* Customer
* Merchant/Admin
Main modules mentioned in the HLD:
* Profile Service
* Product Service
* Cart Service
* Order Service
* Wallet Service
* Website Controller

2. 3-Layer Architecture
The system follows:
1. Controller Layer (Presentation)
Handles HTTP requests.
Controllers:
* AuthController
* ProductController
* CartController
* OrderController
* WalletController
* ProfileController
Responsibilities:
* Accept API requests
* Validate input
* Call services
* Return API responses

2. Service Layer (Business Logic)
Implements core application logic.
Services:
* AuthService
* ProductService
* CartService
* OrderService
* WalletService
* ProfileService
Responsibilities:
* Handle business rules
* Manage cart logic
* Handle order placement
* Process wallet transactions

3. Repository Layer (Data Access)
Handles database operations.
Repositories:
* UserRepository
* ProductRepository
* CartRepository
* OrderRepository
* WalletRepository
* TransactionRepository
Responsibilities:
* Database CRUD operations
* Query handling
* Data persistence

10. Cart Service Logic (Pseudo)
addItem(productId, qty):

product = productRepository.findById(productId)

if product.stock < qty
    throw "Product out of stock"

cart = cartRepository.getCart(userId)

if cartItem exists
    update quantity

    insert new cart item

update cart total
return updated cart

11. Wallet Payment Logic
processPayment(userId, amount):

wallet = walletRepository.getWallet(userId)

if wallet.balance < amount
    throw InsufficientBalanceException

wallet.balance -= amount

transactionRepository.save(
    walletId,
    amount,
    "DEBIT"
)

return paymentSuccess

14. Key Functional Flows
User Registration
1. User enters details
2. AuthService validates
3. UserRepository saves user
Add to Cart
1. Product selected
2. CartService adds item
3. CartRepository updates database
Checkout
1. Cart validated
2. Wallet/COD selected
3. Order created
Order History
1. User requests orders
2. OrderRepository fetches history
